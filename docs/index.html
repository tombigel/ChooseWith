Choose With

Don't just open with. Choose with.

Pick the file types you want. Opening one of them — double-click, ⌘↓, or open in Terminal — shows a menu at your pointer with every app that can open it.

Three slicers, one file type. Pick the right one each time — the rest wait under More Apps.

Your order, your apps

Drag apps into the order you want for each file type, and hide the ones you never use. A .svg can have twenty apps; your menu can have three.

Fast from the keyboard

Return opens the first app, 1–9 pick the others, Esc cancels. The app you chose last comes first next time.

Keeps its place

Apps sometimes make themselves the default. Choose With notices, warns you in the menu bar, and can take the file type back automatically.

How it works

  1. Add file types

    Open Choose With and type the extensions you want a choice for — 3mf, svg, md.

  2. Open a file

    Choose With is now their default, so opening one shows the menu right at your pointer.

  3. Choose

    Pick an app and the file opens in it. Remove a file type any time and it goes back to the app it used before.
