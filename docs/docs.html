Choose With docs

Choose With becomes the default app for the file extensions you pick. Opening one of those files shows a menu at your pointer with every app that can open it.

Install

With Homebrew

Homebrew asks you to trust a third-party tap once before installing from it.

brew tap tombigel/tap
brew trust tombigel/tap
brew install --cask choose-with

This installs Choose With in Applications and puts the choosewith command on your PATH.

Download

Get ChooseWith-<version>.zip from the latest release, unzip it, and move ChooseWith.app to Applications. It's signed with a Developer ID and notarized by Apple, so it opens without warnings.

RequiresmacOS 13 Ventura or later. Universal: Apple Silicon and Intel.

Getting started

  1. Open Choose With from Applications or Spotlight. Settings opens.
  2. Type the extensions you want a choice for in the field at the bottom of the list, for example 3mf, svg, md, and press Return.
  3. Turn on Start at login so the menu is instant after a restart.
  4. Open one of those files in Finder. The menu appears at your pointer.

Choose With keeps running in the background without a Dock icon. Open the app again, or use its menu bar icon, to get back to Settings.

Using the menu

ReturnOpen the first app. It starts highlighted. 1… through 9: open the first nine apps. EscClose the menu without opening anything.
  • Order. The app you chose last for an extension is listed first, unless you've set your own order for it.
  • More Apps. Apps you've hidden are one step away in this submenu.
  • Several files. Select several and open them together; only apps that can open all of them are listed.
  • Other… picks any app. Show in Finder reveals the files.
  • Choose With Settings… at the bottom opens Settings.

Settings

Open Choose With from Applications or Spotlight, press ⌘, while it's running, or choose Choose With Settings… at the bottom of any menu.

Extensions

  • Add extensions in the field at the bottom of the list. Separate several with commas or spaces.
  • The trash button removes an extension and gives it back to the app that opened it before.
  • Each row shows the app count and, if another app has taken the extension, an orange Opens in … label with a Take Back button.
Can't addApps, folders, disks, aliases and links. Taking over .app would put a menu in front of launching every app, so these always open as usual.

App lists

The pencil next to an extension opens its app list.

  • Reorder: drag apps, or right-click one for Move to Top, Up, Down or Bottom.
  • Hide: untick apps you rarely use. They move under More Apps in the menu.
  • Show All, Hide All and Reset are at the bottom. Reset returns to the default order with every app shown.
  • The list stays in sync with installed apps. New apps are added at the end, shown.

Takeovers

Apps can make themselves the default for a file type, often when they're installed or updated. Choose With watches for this.

  • With “Take extensions back” off (the default), you're warned: the menu bar icon turns orange with a count, and Settings shows a banner with Take It Back and Take Back All.
  • With it on, Choose With switches extensions back automatically, posts a quiet notification, and notes it on the extension's row.
LimitIf an app re-claims the same extension 3 times within an hour, Choose With stops and leaves it to you, so the two apps don't fight.

Appearance

Show or hide the menu bar icon, the splash screen, and Help when opening Choose With.

Menu bar icon

  • Lists your active extensions; the full list is in a submenu. Click one to open its app list.
  • Has Settings, How it works?, About, GitHub, Report a Bug, Start at Login, Hide Menu Bar Icon and Quit.
  • Turns orange when another app has taken an extension, and offers Take Back.

When the icon is hidden, open the app again to get back to Settings.

Export and import

Move your setup to another Mac, keep it with your dotfiles, or put it in iCloud Drive.

  • Export… in Settings saves your extensions, app lists and settings as JSON. The file is named with the Mac and the date, like Choose With Settings - Studio Mac - 2026-11-25.json, and records the same in an info entry, with the app version.
  • Import… shows where and when the file was exported and exactly what will change, before applying anything. It replaces this Mac's setup with the file's.
  • Per-Mac things aren't included: Start at login, which app each extension goes back to, and take-back history.
Safe to importAn imported file is treated as untrusted: only regular files up to 1 MB are read, every extension and app ID is validated, and nothing in it is ever run.

Command line

Everything in Settings is also available from the terminal, and a running copy of the app picks up changes right away. Homebrew puts choosewith on your PATH; otherwise use the app's own binary:

/Applications/ChooseWith.app/Contents/MacOS/ChooseWith --help

Apps can be given by bundle ID or by name, in any letter case.

Extensions

OptionWhat it does
--register ext …Use the Choose With menu for these extensions.
--unregister ext …Give them back to the app that opened them before.
--unregister-allDo that for every extension, for example before uninstalling.
--restore ext=bundle.id …Hand an extension to a specific app.
--statusExtensions, their state, and all settings.
 
choosewith --register 3mf svg md
choosewith --status

Apps in the menu

OptionWhat it does
--list extApps for the extension, in menu order, hidden ones marked.
--order ext app[,app …]Put these apps first, in this order.
--hide ext app …Move apps under More Apps.
--show ext app …Show hidden apps again.
--reset extDefault order, all apps shown.
 
choosewith --order 3mf OrcaSlicer,BambuStudio
choosewith --hide svg Safari "Google Chrome"

Takeovers

OptionWhat it does
--take-back on|offTake extensions back automatically.
--take-back-nowTake back every extension another app claimed.

Export and import

OptionWhat it does
--export [file|folder]Write settings as JSON. No argument prints it; a folder gets a file named with the Mac and date.
--import fileReplace this Mac's setup with the file's.
--import file --dry-runOnly show what would change.
 
choosewith --export ~/Desktop
choosewith --import settings.json --dry-run

Settings

OptionWhat it does
--login on|offStart at login.
--menubar on|offMenu bar icon.
--splash on|offSplash screen when opening Choose With.
--help-on-launch on|offHelp window when opening Choose With.
--helpList every option.

Updating

With Homebrew:

brew upgrade --cask choose-with

If you downloaded it, replace the app with the one from the latest release. Your settings are kept either way.

Uninstalling

First give your extensions back to the apps that opened them before — the trash button next to each in Settings, or:

choosewith --unregister-all

Then quit Choose With from its menu bar icon and delete the app, or with Homebrew (--zap also removes its settings):

brew uninstall --cask --zap choose-with
Skip step oneand macOS picks another app for those extensions on its own.

Privacy

Choose With makes no network connections and collects nothing. Its settings are stored locally in ~/Library/Preferences/com.tombigel.ChooseWith.plist. The only links it opens are the website, GitHub and bug-report links you click.

Building from source

git clone https://github.com/tombigel/ChooseWith.git
cd ChooseWith
./build.sh

Builds ChooseWith.app and installs it to ~/Applications. It signs with your Developer ID certificate if one is in the keychain, or ad hoc otherwise. See the README for notarizing and releases.
